CX Intelligence: Dashboard Komplain

Proyek pribadi · Google Sheets, Apps Script, HTML & JavaScript

  • Mengubah catatan komplain di Google Sheets menjadi dashboard khusus Customer Experience, lengkap dengan kartu KPI dan grafik.
  • Komplain dicatat harian lewat form web, lalu otomatis masuk ke kolom sheet yang sesuai.
  • Kategori dibuat terstandar: channel marketplace, faktor (internal/eksternal), jenis (fulfillment, logistik, miss information), dan solusi (tukar, pengembalian, kirim ulang).
  • Mencatat rating sebelum dan sesudah penanganan, sehingga dampak penanganan komplain bisa dibandingkan.
  • Dilengkapi login PIN, pengelolaan user, dan ekspor laporan ke CSV, Excel, PDF, dan PPT.

Marketplace CRM & Complaint Analytics

Proyek pribadi, dalam pengembangan · Next.js, TypeScript, PostgreSQL (Supabase), Tailwind CSS

  • Website CRM multi-tenant untuk penjual di marketplace: tiap perusahaan memiliki login sendiri dan hanya melihat datanya sendiri (Row-Level Security).
  • Menghubungkan ekspor data penjualan Seller Center, ulasan, dan file komplain Excel secara otomatis.
  • ID pesanan menjadi kunci utama pencocokan. Nomor resi dan identitas pelanggan anonim hanya pendukung, dan data yang meragukan tidak dipaksakan cocok.
  • Setiap data diberi status MATCHED, UNMATCHED, NEEDS_REVIEW, atau INVALID agar mudah ditinjau.
  • Sudah memiliki login, impor penjualan, halaman detail pesanan, dan mesin pencocokan. Dikerjakan bertahap, dimulai dari audit file dan pemetaan kolom sebelum menulis kode.
